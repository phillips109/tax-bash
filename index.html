tax-bash

A powerful bash script for handling your tax calculations.

View on GitHub

About

Tax-Bash simplifies the complex process of tax estimation directly from your terminal. Whether you are a freelancer or just love the command line, this tool helps you crunch numbers quickly without leaving your shell.

Installation

Clone the repository and make the script executable:

git clone https://github.com/phillips109/tax-bash.git
cd tax-bash
chmod +x tax-bash.sh

Usage

Run the script by passing your income as an argument:

./tax-bash.sh --income 50000 --year 2024

Or use the interactive mode:

./tax-bash.sh --interactive

Features

  • 🚀 Fast: minimal overhead, runs instantly.
  • 🔒 Private: all calculations happen locally on your machine.
  • 🐧 Bash Native: zero dependencies required.
