# How to run tax-bash
You should create your own copy of the phillips109/tax-bash repository by forking it.
Next you should clone your fork to obtain the files on your local computer.
On your local computer, create a run directory.
It may have any name or location. 
For these instsructions, lets assume you chose ~/RunTaxBash
into this directory you will copy two local files:
Tax-bash.Formfactory/T22/T22.tar.gz
Tax-bash/Formfactory/T22/untar.sh
To run tax-bash, change directory to T22/Main
enter ./tax-bash

NOTE: This process creates a directory and files that are not part of a repository and are not tracked by git.
Therefore you can enter your personal data and it will not be broadcast on the web.
